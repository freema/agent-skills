# Talk prep — checklist

## Before writing

- [ ] Red thread written in ≤ 2 sentences. Passes: one sentence? new? interesting to *them*? realistic?
- [ ] Audience named: who they are, what they already know, why they should listen.
- [ ] Time slot known → plan for 80 %. Word budget = minutes × 0.8 × 150.
- [ ] Question policy decided (during vs. at the end) and said in the intro.

## Structure

- [ ] Intro ≈ 20 %: contact with the room, hook (story / quote / fact / open question / statistic), link to red thread, goal, why listen, structure.
- [ ] Core ≈ 70 %: 3–4 beats, one per slide, each advancing the thread. Ethos + pathos + logos all present.
- [ ] Close ≈ 10 %: summary → red thread → recommendation / challenge / example / quote. Nothing new after the summary.

## Slides

- [ ] One idea per slide; ≤ 5 one-line bullets or one sentence + one picture.
- [ ] One typeface, ≤ 3 sizes, ≤ 3 colours, consistent alignment and spacing.
- [ ] Every number has a source and a date on the speaker-notes side.
- [ ] Memes: real templates, text in the audience's language, ≤ 3 per 5 minutes.
- [ ] Demo has a fallback (screenshot or recording) on the next slide.
- [ ] Deck opens from `file://`, both themes checked, videos play muted.

## Rehearsal

- [ ] Read aloud with a timer. Under 80 % of slot? If not, cut a beat, not words.
- [ ] Opening 30 s and closing sentence learned verbatim.
- [ ] Pauses marked in the talk track after key sentences.
- [ ] Objection sheet: 5–7 expected pushbacks, each with a positive reformulation and a *How/What* hand-back.
- [ ] Practised once standing, with the clicker, in front of one person.

## On the day

- [ ] Arrive early, test projector / clicker / sound.
- [ ] Breathe. Make eye contact before the first word.
- [ ] Slow with pauses beats fast without.
- [ ] Stop at the summary. Thank. Silence is fine.
